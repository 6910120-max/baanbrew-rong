# บ้านบรู Dashboard

Dashboard ยอดขายร้านบ้านบรู สร้างด้วย React + Vite, Tailwind CSS v4, Recharts และ PapaParse

- ตัวกรองช่วงเวลา (7/30/90 วัน, 12 เดือน, กำหนดเอง) + สาขา + ช่องทาง ทุกกราฟคำนวณตามตัวกรอง
- KPI 4 ตัว พร้อม % เปลี่ยนแปลงเทียบช่วงก่อนหน้า
- ยอดขายรายวัน + ค่าเฉลี่ย 7 วัน, ยอดขายรายเดือน + คาดการณ์เดือนถัดไป (linear regression)
- ยอดขายแยกสาขา, สินค้าขายดี 10 อันดับ, ยอดขายตามชั่วโมง, heatmap วัน × ชั่วโมง
- สัดส่วนช่องทางขายและวิธีชำระเงิน, สมาชิก vs ลูกค้าทั่วไป, กลุ่มลูกค้า RFM, สินค้าที่มักซื้อคู่กัน
- ทุกการ์ดสลับดูเป็นตาราง และดาวน์โหลด CSV ได้, พิมพ์/บันทึก PDF ได้
- ภาษาไทย/อังกฤษ, ชุดสี 3 แบบ (เขียว/กาแฟ/ฟ้าคราม), โหมดสว่าง/มืด/อัตโนมัติ, รองรับมือถือ

เว็บที่ deploy แล้ว: https://baanbrew-rong.vercel.app

## วิธีรัน

1. ติดตั้งแพ็กเกจ

   ```bash
   npm install
   ```

2. ข้อมูลตัวอย่างอยู่ที่ `public/sales.csv` (ข้อมูลฝึกจากรายวิชา) ถ้าจะใช้ไฟล์อื่น ให้แทนที่ไฟล์นี้ หรือกดปุ่ม "เปลี่ยนไฟล์ข้อมูล" บนหน้าเว็บ
   คอลัมน์ที่ต้องมี:

   ```
   order_id,datetime,branch,product_id,qty,unit_price,customer_id,payment_method,channel
   ```

3. รัน dev server แล้วเปิด http://localhost:5173

   ```bash
   npm run dev
   ```

## โครงสร้าง

- `src/lib/metrics.js`: logic คำนวณทั้งหมด (KPI, รายวัน/รายเดือน, คาดการณ์, แยกสาขา/สินค้า/ชั่วโมง, RFM, สินค้าซื้อคู่กัน)
- `src/lib/i18n.jsx`: ข้อความภาษาไทย/อังกฤษ
- `src/index.css`: ชุดสีทั้ง 3 แบบ × โหมดสว่าง/มืด (CSS variables)
- `src/lib/format.js`: จัดรูปแบบตัวเลข (฿ และจุลภาค) และวันที่ภาษาไทย
- `src/components/`: KPI card และกราฟ
